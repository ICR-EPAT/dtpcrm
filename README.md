# dtpcrm
Dose Transition Pathways with Continual Reassessment Method

## Features
* Design and Conduct an applied CRM and TITE-CRM with practical considerations which include stopping early for excessive toxicity and when sufficient number of subjects have been dosed at the Maximum Tolerated Dose
* Produce Dose Transition Pathways which can be used as a design tool to aid finer calibration of the CRM model or as a trial conduct tool 

## Author Contributions
Yap conceived and designed the modified CRM with DTP, building on the dfcrm package with added practical considerations and wrote the initial codes. Slade re-wrote the codes with support from Yap and Brock. Pan contributed to the codes, reviewed and compiled them.
